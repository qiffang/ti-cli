# TiDB Cloud CLI v0.2.7

This release changes how the macOS and Linux installer fetches the bundled `ti-drive9` companion so installs succeed in environments that cannot reliably reach Drive9's previous download host.

## What's new

- `install.sh` downloads `ti-drive9` and its checksums from `https://releases.drive9.ai/latest/` (S3 + CloudFront) instead of Drive9's origin or GitHub raw URLs. Checksum verification is unchanged.
- The PowerShell installer and `ti update` still use Drive9's origin release endpoint.

## Upgrade from v0.2.6

Drain and unmount active Filesystem mounts before replacing `ti` and its bundled `ti-drive9` companion, then run:

```bash
ti update --check
ti update
ti --version
```

New installations can use:

```bash
curl -fsSL https://github.com/tidbcloud/ti-cli/releases/download/v0.2.7/install.sh | sh -s -- --yes
export PATH="$HOME/.ti/bin:$PATH"
ti --version
```
